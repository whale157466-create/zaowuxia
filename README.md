# 造物匣手工电商平台 🎁
> 实习实训项目｜面向手工创作者的文创电商平台

[![](https://img.shields.io/badge/Vue3-TypeScript-42b883.svg)]()

## 📖项目介绍
造物匣是面向手工爱好者的B2C电商系统，实现完整电商业务闭环。

普通用户完成商品浏览、购物、下单流程；管理员完成后台内容管理。
