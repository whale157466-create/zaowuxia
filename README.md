## 📖项目介绍
造物匣是面向手工爱好者的B2C电商系统，实现完整电商业务闭环。
普通用户完成商品浏览、购物、下单流程；管理员完成后台内容管理。

## 🛠技术栈
- **前端**：Vue3、Vite、Element‑Plus、TypeScript、Axios
- **后端**：Node.js
- **数据库**：SQLite

## ✨核心功能
### 用户端
- 用户注册、登录
- 商品列表、分类筛选、商品详情
- 购物车管理、订单创建

### 管理端
- 商品新增、编辑、上下架
- 用户信息管理
- 订单查看与状态更新
